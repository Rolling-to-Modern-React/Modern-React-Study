# 🧠 Modern React Study

> 🎯 **RollingPaper 프로젝트**로 함께 리액트를 처음 다뤄본 팀이,  
> 이후에도 함께 공부하며 성장하기 위해 만든 **모던 리액트 스터디 레포지토리**입니다.  
>  
> 📚 _“모던 리액트 Deep Dive (김용찬 저)”_ 를 함께 읽고,  
> 각자 느낀 점과 실습, 코드를 공유하며 리액트를 더 깊이 이해하는 것을 목표로 합니다.

---

## 🚀 목표
- React의 핵심 개념과 렌더링 구조를 깊이 이해하기  
- 책 내용을 단순히 읽는 것을 넘어서, **깊게 이해**하기  
- 팀 단위 코드 리뷰와 토론으로 **‘왜 이렇게 동작하는가’를 중심으로 함께 학습**

---

## 📚 스터디 방식

| 단계 | 내용 |
|------|------|
| ① | 각자 책의 챕터별 내용을 읽고 정리 |
| ② | 각자 맡은 파트의 관련 내용을 작성 |
| ③ | 시간을 맞추어 파트 나눠서 설명 |
| ④ | 정리/리뷰/피드백 |

---

```
modern-react-study/
 ┣ 01. 리액트 개발을 위해 꼭 알아야 할 자바스크립트/

 ┣ 06. 리액트 개발도구로 디버깅하기/
 ┣ 07. 크롬 개발자 도구를 활용한 애플리케이션분석/
 ┣ 08. 좋은 리액트 코드 작성을 위한 환경 구축하기/
 ┣ 09. 모던 리액트 개발 도구로 개발 및 배포 환경 구축하기/

 ┣ 11. Next.js 13과 리액트 18/

 ┣ 📄 README.md
```

## 🗓️ 진행 주기
- 프로젝트 기간을 제외한 주 3회(월, 수, 금) 온라인 회의
