## 1.2.2 함수를 정의하는 4가지 방법

### 핵심 개념 요약

리액트 애플리케이션 내부에서 다양한 방식으로 함수를 정의하며 호출 방식에는 기술적인 차이가 있다.

**함수 선언문**

- 자바 스트립트에서 함수를 선언할 때 가장 일반적으로 사용하는 방식
- 표현식이 아닌 문(statement)으로 분류 된다.

<aside>
💡

*표현식 이란? 
무언가를  값을 산출하는 구문을 의미 한다. 즉, 함수 선언문으로는 어떠한 값도 표현되지 않았으므로 표현식이 아닌 문으로 분류 된다.*

</aside>

```jsx
function add(a, b) {
	return a + b
}

const sum = function sum(a,b) {
	return a+b
}

sum(10,24) // 24
```

- 자바스크립트 엔진이 코드의 문맥에 따라 동일한 함수를 문이 아닌 표현식으로 해석하는 경우가 있어 위와 같이 이름을 가진 형태의 함수 리터럴(함수를 직접 작성하여 값을 생성하는 표기법)은 코드 문맥에 따라 선어문, 표현식으로도 사용 될 수 있다.

**함수 표현식**

<aside>
💡

*일급 객체`¹` 란?*

*다른 객체들에 일반적으로 적용 가능한 연산을 모두 지원하는 객체를 의미하며, 자바스크립트에서 함수는 일급 객체이다.*

*⇒ 함수는 다른 함수의 매개변수가 될 수도 있고, 반환값이 될 수도 있으며, 할당도 가능하기 때문!*

</aside>

- 함수 표현식에서는 할당하려는 함수의 이름을 생략하는 것이 일반적이다.(혼란 방지)

- 함수 표현식과 선언문의 차이 - # 함수 호이스팅
    - 함수 선언문이 마치 코드 맨 앞단에 작성된 것처럼 작동하는 자바스크립트의 특징
    - 함수 선언문 - 함수가 선언된 위치와 상관없이 어디서든 호출 가능, 변수 선언과 구별 됨
    
    ```jsx
    hello() //  hello
    
    function hello() {
    	console.log('hello');
    }
    
    hello() // hello
    ```
    
    - 함수 표현식
    
    ```jsx
    console.log(typeof hello === 'undefinded') // true
    
    hello() // Uncaught TypeError : hello is not a function
    
    var hello = function() {
    	console.log('hello');
    }
    
    hello()
    ```
    
    그러나 함수가 선언 되기 전에 함수가 호출 되는 것이 이상하게 느껴질 수도 있고, 개발자가 해당 스코프를 끝까지 확인해야 하는 어려움이 발생할 수 있기 때문에 일관된 방법을 사용하는 것이 중요!
    

**Function 생성자**

```jsx
const add = new Function('a', 'b', 'return a+b');

add(10, 24) // 34
```

- 코드작성 관점에서 볼 때, 매개 변수와 함수의 몸통을 모두 문자열로 작성해야 하는 방식이다. (어려움)
- 생성자 방식으로 함수를 만들면 함수의 **클로저**`²` 또한 생기지 않는다.
- 권장되지 않는 방법이다.

**화살표 함수**

```jsx
const add = (a, b) => {
	return a + b
}

const add = (a, b) => a + b
```

- ES6에서 새롭게 추가된 함수 생성 방식으로 function 이라는 키워드 대신 ⇒ 라는 화살표를 활용
- constructor(생성자 함수)를 사용할 수 없다.
- arquments가 존재하지 않는다.
- 화살표 함수와 일반함수의 가장 큰 차이점 : this 바인딩

- 화살표 함수의 특징 - # this
    - 일반 함수 호출 : 전역 컨텍스트에서는 this가 window(브라우저 환경) 또는 global(Node.js 환경)을 가리 킴
    - 메서드 호출 : 객체의 메서드로 호출하면, this는 그 객체를 가리 킴
    - 생성자 함수 : new 키워드로 호출하면, this는 새로 생성된 인스턴스를 가리 킴
    - 화살표 함수 : 화살표 함수는 자신만의 this를 가지지 않고, 상위 스코프의 this를 그대로 사용
    - 이벤트 핸들러 : DOM 이벤트에서 this는 이벤트가 바인딩된 요소를 가리 킴
    
    ```jsx
    function foo() {
      console.log(this);
    }
    foo(); // window 또는 global
    
    const obj = {
      bar: function() {
        console.log(this);
      }
    };
    obj.bar(); // obj
    
    function Person(name) {
      this.name = name;
    }
    const p = new Person('Tom');
    console.log(p.name); // Tom
    
    const arrow = () => {
      console.log(this);
    };
    arrow(); // 상위 스코프의 this
    ```
    
    특히 react에서 this는 주로 클래스형 컴포넌트 이며, state, props, 컴포넌트 내 메서드 등을 가리키는 데 사용되는 자기 참조 변수이다. (this.state, this.props 등)
    

### 질문 및 토론 사항

1. **클로저**`²` 에 대해서 토론해 보기
- **일반 함수**: 선언된 위치의 스코프(렉시컬 환경)를 기억 → 클로저 형성
