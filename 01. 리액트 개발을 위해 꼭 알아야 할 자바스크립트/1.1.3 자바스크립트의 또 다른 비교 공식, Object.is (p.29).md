##  1.1.3 자바스크립트의 또 다른 비교 공식, Object.is

### 핵심 개념 요약

1. **Object.is**()란?
- 두 개의 인수를 받으며, 두 인수가 동일한지 확인하고 반환하는 메서드다.
- == (동등 연산자) 비교는 비교 이전에 양쪽이 같은 타입이 아니라면 강제로 형변환을 한 후에 비교 한다.
- ===(**일치 연산자)** 비교에서는  `NaN`, `-0`, `+0`에 대한 특수 처리를 포함하여 수행하며, 형변환을 하지 않는다.
- **Object.is**() 는 `NaN`, `-0`, `+0`에 대한 형식 변환과 특수 처리를 수행하지 않는다. (특수 숫자 값을 제외하고 `===`와 동일한 동작 제공)

```jsx
-0 === +0 // true
Object.is(-0, +0) // false

Number.NaN === NaN // false
Object.is(Number.NaN, NaN) // true

NaN === 0 / 0 // false
Object.is(NaN, 0 / 0) // true
```

1. 주의해야할 점
- **Object.is**를 사용한다고 하더라도 객체 비교에서는 별 차이가 없다. ([객체 비교 원리와 동등 - 1.1.2](https://www.notion.so/1-1-2-p27-2709e7924575800a82d5db9a9c9c4542?pvs=21))
- **Object.is**는 ES6에서 새롭게 도입 된 비교 문법으로 특별한 사항에서 동등비교가 가지는 한계를 극복하기 위해서 만들어졌다. 그러나 여전히 객체 간 비교에 있어서는 여전히 === 와 동일하게 동작한다.
