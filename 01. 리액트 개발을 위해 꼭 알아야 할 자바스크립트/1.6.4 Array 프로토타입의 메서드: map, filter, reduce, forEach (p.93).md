## 1.6.4 Array 프로토타입의 메서드: map, filter, reduce, forEach

### 핵심 개념 요약

`Array.prototype.map`, `Array.prototype.filter`, `Array.prototype.reduce`는 모두 배열과 관련된 메서드 이다. JSX 내부에서 배열을 조작해 바로 원하는 JSX를 반환하는 특성상 이 3개의 메서드가 자주 쓰인다. 또한, 기존 배열의 값을 건드리지 않고 새로운 값을 만들어내기 때문에 안전하다. `forEach`까지 포함해 ES5에서부터 사용한 문법으로 별도의 트랜스파일이나 폴리필 없이도 부담 없이 사용할 수 있다.

**Array.prototype.map**

- `Array.prototype.map`은 인수로 전달받은 배열과 똑같은 길이의 새로운 배열을 반환한다.
- 배열의 각 아이템을 순회하면서 각 아이템을 콜백으로 연산한 결과로 구성된 새로운 배열을 만들 수 있다.

```jsx
const arr = [1,2,3,4,5];
const doubleArr = arr.map(item => item * 2) // [2, 4, 6, 8, 10]
const Elements = arr.map((item) => {
	return <Fragment key={item}>{item}</Fragment>
})
```

**Array.prototype.filter**

- `Array.prototype.filter`는 콜백 함수를 인수로 받아 콜백 함수에서 truthy 조건을 만족하는 경우에만 해당 원소를 반환하는 메서드다. (필터링 역할)
- 결과에 따라 원본 배열 길이 이하의 개로운 배열이 반환된다.

```jsx
const arr = [1,2,3,4,5];
const evenArr = arr.filter((item) => item % 2 === 0) // [2, 4]
```

**Array.prototype.reduce**

- `Array.prototype.reduce`는 콜백 함수와 함께 초기값을 추가로 인수를 받는데, 이 초기값에 따라 배열이나 객체, 또는 그 외의 다른 무언가를 반환할 수 있는 메서드이다.
- `Array.prototype.reduce`는 `reducer` 콜백 함수를 실행하고, 이를 초기값에 누적해 결과를 반환한다.

```jsx
const arr = [1,2,3,4,5];
const sum = arr.reduce((result, item) => {
return result + item
}, 0) // 15
```

- `0`은 `reduce`의 결과를 누적할 초기값이다.
- `reducer` 콜백 함수의 첫 번째 인수는 앞서 선언한 초기값의 현재값을 의미하고, 두 번째 인수는 현재 배열의 아이템을 의미한다.
- 콜백의 반환값을 계속해서  초기값에 누적해 새로운 값을 만든다.

- ***filter와 map의 조합과 reduce를 사용한 배열 처리 비교***
    - `reduce`는 단순한 합계를 구하는 것뿐만 아니라 배열을 원하는 하나의 객체로 변환하는 등의 예제에서 사용 됨
    - `filter`와 `map`의 작동을 `reduce` 하나로도 구현할 수 있는데 비교적 직관적이지 않으므로 짧은 코드엔 `filter`와 `map`을 각각 활용해 구현하는 것도 나쁘지 않은 방법
    
    ```jsx
    // 짝수만 100을 곱해 반환하는 함수 예제
    const arr = [1,2,3,4,5];
    
    // [200, 400] - filter, map의 조합
    const filterAndMapResult = arr.filter(item => item % 2 === 0).map(item => item * 100);
    
    // [200, 400] - reducer로 처리
    const reducerResult = arr.reduce((result, item) => {
      if(item % 2 === 0) {
        result.push(item * 100)
      }
      return result
    }, [])
    ```
    

**Array.prototype.forEach**

- `Array.prototype.forEach`는 콜백 함수를 받아 배열을 순회하면서 단순히 그 콜백 함수를 실행하기만 하는 메서드이다.

 

```jsx
const arr = [1,2,3,4,5];

const result = arr.forEach(num => console.log("num : ", num)) // 1,2,3,4,5
```

- `forEach`는 아무런 반환값이 없다. (단순히 콜백 함수 실행)
- `forEach`의 반환값은 `undefined`로 의미가 없다.
- 실행되는 순간 에러를 던지거나 프로세스를 종료하지 않는 이상 멈추지 못한다. (`break`, `return`도 소용 x)

```jsx
function run(){
	const arr = [1, 2, 3];
	arr.forEach((item) -> {
		console.log(itme)
		if(item === 1){
			console.log('finished!');
			return;
		}
	})
}

// 이 함수를 실행하면 다음과 같은 결과를 볼 수 있다.
run()

// 1
// finished!
// 2
// 3
```

- return이 함수의 return이 아닌 콜백함수의 return으로 간주되어 forEach 콜백이 실행되게 된다.
- forEach 내부의 콜백 함수는 무조건 **O(n)**만큼 실행되므로 코드 작성시 최적화 가능성을 검토해야 한다.

<aside>
💡

"O(n)"은 빅오 표기법(Big O notation)으로, 알고리즘의 시간 복잡도를 나타내는 표기법

이 문맥에서는 forEach 메서드가 배열의 모든 요소를 순회하기 때문에 배열의 길이(n)에 비례하는 시간이 걸린다는 의미입니다. 즉, 배열에 있는 모든 요소를 하나씩 처리하므로 배열의 크기가 n이라면 콜백 함수가 정확히 n번 실행된다는 것을 나타냅니다.

</aside>
