### 리액트의 렌더링 프로세스
#### 렌더링(Rendering) 이란?
- 리액트 컴포넌트가 실제 브라우저 화면에 그려지는 과정
- 렌더링이 시작되면, React는 루트 컴포넌트부터 아래로 내려가며 변경이 필요한 컴포넌트만 찾아서 업데이트함

#### 함수 VS 클래스 렌더링 방식
- **클래스 컴포넌트:** 내부의 `render()`함수를 실행하여 결과 반환함
- **함수 컴포넌트:** 함수 자체 `functionComponent`를 실행하고 그 결과를 저장함
> 렌더링 과정에서 클래스는 render 메서드, 함수는 컴포넌트 함수 자체를 호출함.

#### JSX 처리 방식 (createElement 변환 과정)
- JSX는 실제로 `React.createElement()`를 호출해서 화면을 그릴 수 있는 자바스크립트 객체를 구성함

#### 렌더링 이후 과정
- 렌더링된 결과물 (가상 DOM)을 리액트 내부 트리에서 비교하고 변경된 부분만 실제 DOM에 반영함
- 이 과정을 재조정이라 부르며 모든 변경 사항이 반영되면 브라우저 화면에 최종 결과가 보임

### 
```tsx
// 1. JSX로 작성한 코드
function Hello() {
  return (
    <TestComponent a={35} b="yceffort">
      안녕하세요
    </TestComponent>
  );
}

// 2. React는 내부적으로 변환하는 실제 코드
// JSX는 브라우저가 이해하지 못하므로, React.createElement() 함수로 자동 변환됨
function Hello() {
  return React.createElement(
    TestComponent, // ✔️ type : 어떤 컴포넌트인지
    { a: 35, b: "yceffort" }, // ✔️ props : 전달된 데이터
    "안녕하세요" // ✔️ children : 태그 안의 자식 요소
  );
}

// 3. React가 최종적으로 만드는 요소 객체 -> 실제 DOM이 아니라 화면 구성을 설명하는 자바스크립트 객체
{
  type: TestComponent,
  props: {
    a: 35,
    b: "yceffort",
    children: "안녕하세요"
  }
}
```

#### JSX → React.createElement() → UI 정보 객체 생성 → 브라우저에 실제 DOM 반영
