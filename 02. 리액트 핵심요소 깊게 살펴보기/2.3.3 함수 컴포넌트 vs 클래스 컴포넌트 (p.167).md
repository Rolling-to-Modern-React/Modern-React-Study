
### 핵심 개념 요약

### 1.함수 컴포넌트 vs 클래스 컴포넌트
#### 생명주기 메서드의 부재
- 클래스 컴포넌트에는 `componentDidMount`, `componentDidUpdate`, `componentWillUnmount`같은 생명주기 메서드가 존재함
- 함수 컴포넌트에는 이런 메서드는 없고 대신 `useEffect` 훅으로 비슷한 동작을 구현함
- `useEffect`는 생명주기가 아닌 부수효과(side Effect) 를 관리함
```tsx
// 함수 컴포넌트의 useEffect 예시 (생명주기 동작 흉내냄)
import React, { useEffect } from "react";

export default function Example() {
  useEffect(() => {
    console.log("컴포넌트가 마운트됨"); // ✔️ 컴포넌트가 처음 렌더링될 때
    return () => console.log("컴포넌트가 언마운트됨"); // ✔️ 컴포넌트가 화면에서 사라질 때 -> clean-up 역할
  }, []);

  return <p>함수 컴포넌트 생명주기 예시</p>;
}
```

#### 함수 컴포넌트와 렌더링된 값
- 함수 컴포넌트는 렌더링 때 한번 실행되고 끝나며, 실행될 때의 `props`값을 클로저 안에서 그대로 기억함
- 클래스 컴포넌트는 `this.props`를 계속 참조하기 때문에 값이 바뀌면 실시간으로 반영됨

| 구분       | 참조 방식             | 값의 시점          |
| -------- | ----------------- | -------------- |
| 함수 컴포넌트  | `name` (클로저로 기억)  | **클릭 순간의 값**    |
| 클래스 컴포넌트 | `this.props.name` | **최신 값** |


#### props 갱신 문제 해결법
- 클래스 컴포넌트에서 오래된 props를 참조하지 않게 하려면 두가지 방법이 있음
- 첫째, `this.props`를 더 늦게 호출하도록 함수 인자로 넘기기
- 둘째, `render()`내에서 최신 props를 지역 변수에 저장함
> 이 두 방법 모두 코드가 복잡해지고 성능에도 불리할 수 있음

#### 함수 컴포넌트의 장점
- `props`와 `state`를 함수 인수로 받아 불변성을 유지함
- 렌더링 시 항상 최신 상태를 반영함
- 코드가 간결하고 직관적임
```tsx
// 불변성 기반 함수 컴포넌트
export function UserCard({ name }: { name: string }) {
  return <p>Hello, {name}</p>; // ✔️ props 값이 변경되면 자동으로 재렌더링
}
```

#### 클래스 컴포넌트를 공부해야할까?
- 클래스 컴포넌트가 폐기 예정 계획은 없음
- 리액트 16.8 이후 함수 컴포넌트 + Hook 표준이 되었음
- 기존 코드 유지나 에러 핸들링을 위해 기초 지식은 알아두면 좋음
- 새 프로젝트는 함수 컴포넌트로 시작하는 것이 권장됨
